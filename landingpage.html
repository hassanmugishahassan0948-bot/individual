Origins and Name

• C with Classes (1979): Stroustrup wanted a language that combined the high-level object-oriented features of Simula with the speed and low-level efficiency of C.
• Renamed to C++ (1983): Rick Mascitti suggested the name C++, using the C increment operator (++) to symbolize an enhanced version of C.
• First Commercial Release (1985): Stroustrup published The C++ Programming Language, and the first commercial implementation shipped alongside the Cfront
